# Перенос проекта с сервера

Исходный проект располагался в `/root/lavka`. Это импорт файлов, а не восстановленная история Git: на сервере каталог не был репозиторием.

## Что сохранено

- Текущие `app`, `static`, `scripts`, `tests`, Dockerfile и зависимости перенесены в корень репозитория.
- Старые копии файлов и каталоги `backup_*` из проекта перенесены в `archive/lavka/` с сохранением относительных путей.
- Внешние каталоги `lavka-backups` и `lavka_backup_20260922_184606` сохранены в `archive/`.
- Исходный ZIP проекта распакован в `archive/initial-package/`, чтобы содержимое можно было проверить и сравнивать в Git.
- Прежние README и PROJECT_STATUS из рабочего каталога сохранены в `archive/server-docs/`; `/root/README-1.md` — в `archive/README-1.md`.
- Конфигурация Nginx домена сохранена в `deploy/nginx/lavkashamana.ru.conf`. Сертификаты и приватные ключи не переносились.
- Включены изображения сайта, загруженные фотографии товаров и публичные документы на продукцию.

[import-manifest.json](import-manifest.json) содержит соответствие исходных и новых путей, SHA-256 исходного файла и SHA-256 опубликованной версии. Пути `lavka/...`, `lavka-backups/...`, `lavka_backup_...` и `README-1.md` относятся к `/root`; `initial-package/` — к содержимому исходного ZIP; `etc/` — к `/etc` сервера.

## Исключения

`.env` и его резервные копии, SQL-дампы с данными, Python-кэш и pytest-кэш исключены. Системные каталоги ОС, SSH-ключи, история команд, журналы, Docker-слои и том PostgreSQL не являются исходниками проекта и в Git не загружались. Рабочий каталог товаров, пользователи, заказы и настройки остаются в БД сервера.

## Изменения при подготовке

- В основном Compose и его исторических копиях встроенный пароль PostgreSQL заменён обязательной переменной `POSTGRES_PASSWORD`.
- В основном override абсолютный путь `/root/lavka/static/uploads` заменён на `./static/uploads`.
- В `.env.example` добавлены `POSTGRES_PASSWORD` и `CDEK_SHIPMENT_POINT`, уточнён комментарий к ЮKassa.
- Добавлены актуальный README, описание импорта и правила исключения секретов и архивов из Git/Docker-контекста.
- Логика Python/JavaScript приложения и существующий тест не исправлялись при переносе.

На момент первичного осмотра PostgreSQL был остановлен, API перезапускался, публичный сайт отвечал HTTP 502. Эти сведения описывают момент осмотра, а не постоянный статус сервиса. Сервер в ходе импорта не изменялся.
