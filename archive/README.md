# Архив исходников

Здесь сохранены старые версии и резервные копии проекта с сервера. Рабочая версия находится в корне репозитория. Архивные файлы не входят в Docker-образ и могут содержать устаревший код и документацию.

Секреты и SQL-дампы исключены; встроенный пароль БД в исторических Compose-файлах заменён переменной окружения. Карта исходных путей и контрольные суммы находятся в `../docs/import-manifest.json`.
